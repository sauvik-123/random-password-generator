# 🔐 Random Password Generator

A simple and responsive Random Password Generator built with **React, JavaScript, and Tailwind CSS**. Generate customizable passwords with optional numbers and special characters, and copy them to your clipboard with one click.

## 🌐 Live Demo

🚀 **Try it here:** https://random-password-generator-gamma-one.vercel.app/

## ✨ Features

- 🔑 Generate random passwords instantly.
- 📏 Adjust password length from 6 to 100 characters.
- 🔢 Include or exclude numbers.
- 🔣 Include or exclude special characters.
- 📋 Copy passwords to the clipboard with one click.
- 🔔 Toast notifications for successful copying.
- 📱 Responsive user interface.

## 🛠️ Technologies Used

- React
- JavaScript
- Tailwind CSS
- Vite
- React Hot Toast

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone "https://github.com/sauvik-123/random-password-generator.git"
```

### 2. Navigate to the Project Directory

```bash
cd random-password-generator
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.
